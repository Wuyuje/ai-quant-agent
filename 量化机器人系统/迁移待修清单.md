## 🔴 P0 — 迁移时必修（安全致命）

### 1. SSH 已被暴力破解 20620 次

**现状**：
```
PermitRootLogin yes          ← 允许 root 登录
密码认证: 开启                ← 可被爆破
Failed password: 20620 次    ← 已在被攻击
```

**修复**：
```bash
# ⚠️ 改前必须先配好 SSH 密钥，否则锁死
ssh-keygen -t ed25519                    # 本地生成密钥
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@新IP

sed -i 's/^PermitRootLogin yes/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd

# 装 fail2ban 自动封禁
apt install -y fail2ban
systemctl enable --now fail2ban
```

**风险等级**：🔴 最高（一旦密码被猜中，币安 API Key + 私钥全泄露）

---

### 2. 管理面板接口无鉴权

**现状**（`quant/quant-server.js` 第174-185行）：
```js
this.app.post('/api/quant/close', async (req, res) => {
    const { adminKey, wallet, symbol } = req.body || {};
    // 管理员验证
    // 无需密钥: 管理页面本身已经是管理终端, 进来就能平仓
    // if (!adminKey || adminKey !== (process.env.ADMIN_KEY || '')) {   ← 被注释!
    //   return res.status(403).json({ error: '管理员密钥无效' });
    // }
```

**实测结果**：
```
GET  /api/quant/agents -> 200  泄露所有用户钱包/余额/持仓/盈亏
POST /api/quant/close  -> 无鉴权  可强制平任意用户仓位
```

**修复**：
```js
// 取消注释，恢复 ADMIN_KEY 校验
if (!adminKey || adminKey !== (process.env.ADMIN_KEY || '')) {
    return res.status(403).json({ error: '管理员密钥无效' });
}
```
同时给 `/api/quant/agents` 等敏感 GET 接口加鉴权。

**⚠️ 注意**：修了之后，前端 `admin.html` 调用时必须带上 `adminKey`，需要同步改前端。

**风险等级**：🔴 高（任何人访问 10060 端口即可看全部数据 + 平仓）

### 3. `.env` 权限过宽

**现状**：
```
-rw-rw-r-- 1 10001 10001 591 .env     ← 644，others 可读
-rw-rw-r-- 1 10001 10001  32 data/.admin-key
```

**含敏感字段**：
```
BINANCE_API_KEY / BINANCE_API_SECRET
TRADER_PRIVATE_KEY      ← 私钥
ADMIN_KEY
ENCRYPTION_KEY
OPENROUTER_API_KEY
```

**修复**：
```bash
chmod 600 /root/ai-quant-agent/.env
chmod 700 /root/ai-quant-agent/data
chmod 600 /root/ai-quant-agent/data/.admin-key
```

**风险等级**：🟡 中（本机其他用户/进程可读）
