安全说明
为什么需要您的 API Key？

为了帮您自动交易，系统需要访问您的币安账户。
但我们绝不会要求提币权限 — 您的资金始终在您账户中。

1

只交易，不提币

API Key 只开放「现货交易」权限，无法提币、无法转账。即使密钥泄露，资金也安全。

2

AI 自动交易

7大策略融合分析，24/7不间断运行，毫秒级执行，不错过任何机会。

3

实时监控

仪表盘随时查看持仓、盈亏、交易记录。一键解绑，立即停止。

分步教程

1
登录币安
📱 App端：打开币安App → 登录您的账户
💻 网页端：访问 binance.com → 登录

如果还没有币安账户，需要先注册并完成身份认证。

2
进入 API 管理
💻 网页端（推荐）：点击右上角头像 → 选择「API管理」

或直接访问以下链接：
https://www.binance.com/zh-TC/my/settings/api-management

⚠️ 请确保网址以 binance.com 开头，不要访问钓鱼网站。

3
创建 API 密钥
1. 点击 「创建API」 按钮
2. 选择 「系统生成密钥」
3. 输入标签名，例如：量化机器人
4. 点击「创建」
4
完成安全验证
按提示完成以下验证（根据您的安全设置）：

✉️ 邮箱验证码
📱 手机短信验证码
🔐 Google Authenticator 验证码

完成后，API密钥就创建好了。

5
复制 Secret Key
重要

Secret Key 只显示一次！关闭页面后将无法再次查看。请立即复制保存。

创建成功后会看到两个密钥：

API Key：类似 xK7mN2...
Secret Key：类似 pQ9wR4...

📋 建议截图保存，或复制到记事本。
6
设置 API 权限
⚠️ 最关键

这一步决定您的资金安全！请严格按照以下说明操作。

点击 API 列表右侧的 「编辑」 按钮，然后：

✅ 勾选：「现货和杠杆交易」
❌ 不要勾选：「提币」
❌ 不要勾选：「内部转账」
❌ 不要勾选：「合约交易」（如果有的话）

设置完成后，点击 「保存」

只勾选「现货交易」意味着：系统只能买卖现货，无法将您的币转出。

7
设置 IP 白名单
⚠️ 强烈推荐

设置 IP 白名单后，即使密钥泄露，别人在其他IP也无法使用您的密钥。

1. 在 API 编辑页面，找到 「IP访问限制」
2. 选择 「限制访问此API密钥的IP地址」
3. 添加以下 IP 地址：
正在获取服务器IP...
4. 点击 「确认」 保存

如果暂时不想设置IP白名单，也可以跳过。但我们强烈建议设置。

8
粘贴密钥，完成连接

将刚才复制的密钥粘贴到下方表单中，点击「验证并连接」即可开始自动交易！
