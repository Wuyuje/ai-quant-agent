# BTC 10分钟事件预测系统（独立）
独立的 BTC 涨跌事件预测 + 模拟盘系统，与量化机器人系统分开。

## 结构
- `predict.py / predict2.py` — BTC(15m/1m) 涨跌方向 ML 预测回测（1m/min级别）
- `micro.py / micro_fin.py / micro_long.py` — 秒级(1s)微观结构预测（毫秒级算法，置信度过滤后胜率60%+）
- `opt.py` — 持仓窗口×置信度参数寻优
- `sim_core.py` — 模拟盘核心引擎（实时秒级预测+虚拟资金模拟交易，每55秒一轮）
- `server.js + page.html` — 模拟盘Web服务+专业仪表盘（端口10500，管理员/白名单优先）

## 数据
- Binance 公开接口 data-api.binance.vision（无key，不占账户权重）
- 安全限速：每批请求间隔2-3秒，本地缓存（csv不在git内）
- 1s数据历史约~7天

## 规则（币安事件合约）
- 买入看涨/看跌 → 精确10分钟后判定胜负
- 买多：10分钟后价格>买入价=胜；买空：10分钟后价格<买入价=胜
- 支付率80%（胜率>55.6%保本，60%以上有安全边际）
