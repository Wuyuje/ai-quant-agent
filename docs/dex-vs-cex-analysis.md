## 三、为什么DEX无法盈利

### 核心矛盾

```
策略毛期望值:  +0.304%/笔 (加回CEX成本后的真实策略价值)
CEX往返成本:   0.18%       → 净EV = +0.124%/笔 ✅ 微利
DEX往返成本:   1.50%       → 净EV = -1.196%/笔 ❌ 亏损
```

**DEX比CEX贵 8.3倍**, 每笔多吞噬 **1.32%** 的利润。

## 四、根本原因分析

1. **策略是高频短持仓型** (平均0.5-2小时)
   - 每笔利润小 (+4%), 高频交易放大了成本影响
   - DEX的固定成本(1-1.5%)会吃掉大部分利润

2. **CEX的低成本(0.18%)恰好是策略的盈亏边界**
   - CEX微利 +0.12%/笔 → 100笔赚$6
   - DEX亏损 -1.2%/笔 → 100笔亏$324

3. **DEX杠杆困难**
   - CEX: 原生支持杠杆, 成本按名义值算(0.04% × 名义)
   - DEX: 现货无杠杆, 需借贷(额外利率), 或永续合约DEX(更大滑点)
   - 杠杆后DEX成本更大

4. **滑点是最大成本项**
   - DEX滑点0.5-1% vs CEX滑点0.05-0.1%
   - 小池子滑点更大, 尤其非主流币种

## 五、如果要转DEX需要怎么做

### 方案A: 改变策略风格 (推荐)
- 从高频短持仓改为低频长持仓 (持仓>1天)
- 每笔利润目标从+4%提升到+15-20%
- 交易频率从每天10+笔降到每周2-3笔
- 这样DEX的1.5%成本占比降到 10% 以下

### 方案B: 使用最便宜的DEX路由
- 0x/Matcha RFQ: 做市商竞价, 滑点最低
- Uniswap V3 0.05% pool: 集中流动性, 滑点低
- 仍然需要策略盈亏比>3.0

### 方案C: 只做大池主流币
- BTC/ETH/SOL等大池子滑点<0.1%
- 避免小币种(滑点可能>1%)
- 但主流币波动小, 策略胜率可能更低

### 方案D: 永续合约DEX (dYdX/GMX)
- dYdX: 手续费0.05% × 2 + 滑点0.1% ≈ 0.2% (接近CEX!)
- 但dYdX在Arbitrum, 只支持主流币
- GMX: 0.3% 开仓+平仓费, 滑点低
