# 算力费记账原则（重要）

## 核心原则
1. **各用户钱包地址独立记账**：每个普通用户的算力费充值/扣除严格独立，互不串账。
2. **管理员入账钱包余额可随时取用**：管理员入账钱包（新充值钱包 `0xB5E113DD2fcb87a458191c3B0e2d606129455d4e`）的 USDT 资金池，管理员可随时手动取用/转账。
3. **管理员取用不影响各用户记账数据**：管理员从链上取走资金，不影响各用户账面的 `gatesFeeBalance` 数字。
4. **架构**：账面记账（gatesFeeBalance）决定用户能否开仓；链上资金池（新钱包USDT）由管理员支配。二者分离。

## 记账机制
- 用户充值 USDT 到新充值钱包 `0xB5E113...`
- 登录时系统自动检测"该用户BSC钱包 → 新钱包"的 USDT 转入
- 一次性自动入账到该用户 `gatesFeeBalance`，并记录 `gatesFeeOnchainRecharged`（已入账追踪防重复）
- 余额 < 5U → 自动停止该用户开新仓 + 仪表盘提示
