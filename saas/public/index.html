📖 币安 API Key 创建教程

Step 1 打开币安APP（或访问 binance.com）→ 登录账户
Step 2 点击右下角「用户中心」（人形图标）→ 向下滑动找到「API管理」
Step 3 点击「创建API」→ 选择「系统生成」→ 输入标签名（如：quant）
Step 4 权限设置：✅ 勾选「启用交易」 ❌ 不要勾选「启用提现」
Step 5 完成安全验证 → 创建成功 → 点击「查看」→ 复制 API Key 和 Secret Key
回到本页面 → 点击「已有 Key，直接粘贴」→ 粘贴 Key 和 Secret → 点击「验证并绑定」
⚠ 安全提醒：不要勾选「启用提现」权限！AI 只需要交易权限，不能动用您的资金提现。Secret Key 只显示一次，创建后立即保存到安全位置。
