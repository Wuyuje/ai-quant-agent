📱 Telegram 绑定 4 步（约3分钟）
第1步 · 创建 Bot 拿 Token
① Telegram 搜索 @BotFather（认准蓝色认证勾）
② 点「START」→ 发送 /newbot
③ 起个名字（如：ARK提醒）→ 起用户名（必须 _bot 结尾，如 arkalert_bot）
④ 成功后它会返回一串 8123456789:AAHdqTcv... ← 这就是 Token，完整复制
第2步 · 给 Bot 发消息（关键！）
① 搜索你刚创建的用户名（如 @arkalert_bot）
② 点「START」→ 随便发一句 hi
⚠️ 不做这步会报 "chat not found"
第3步 · 拿你的 Chat ID
① Telegram 搜索 @userinfobot
② 点「START」→ 它立即回复：Id: 123456789
③ 这个数字就是 Chat ID
第4步 · 填入并测试
① 把 Token 填上面「Bot Token」框
② 把数字填上面「Chat ID」框
③ 点下方「发送测试」→ 手机 Telegram 收到 = 成功 ✅
💡 想发到群组？把 Bot 拉进群 → 群里发条消息 → 浏览器打开
https://api.telegram.org/bot你的Token/getUpdates
找 "chat":{"id":-100xxxx} 这个负数就是群 Chat ID
📱 微信配置说明
① 打开 sct.ftqq.com → 微信扫码登录
② 复制「SendKey」（SCT 开头，约 40 位）
③ 粘贴 → 点「发送测试」
④ 微信看 「服务通知」（不是聊天列表）
⚠️ 不要填 wxid_xxx（微信个人号 ID，不是 SendKey）
